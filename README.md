# 여백 로스터스 (YEOBAEK ROASTERS)

가상 스페셜티 커피 로스터리 브랜드의 커머스 사이트 포트폴리오 시안입니다.

- 공개 주소: https://seniordog.kr
- 유형: 쇼핑몰형
- 구성: 홈 / 원두 / 드립백·기구 / 정기구독 / 로스팅 / 저널 / 상품 상세 (해시 라우터 7개 뷰)

## 기술

- 단일 HTML 파일. 외부 요청 0건
- 사진 35장(WebP) · 영상 2개(H.264)를 data URI 로 내장
- 서체 Pretendard(OFL). 사용 글자만 서브셋해 굵기당 약 36KB 로 임베드
- 라이트/다크 · PC/모바일 대응
